# ข้อความแจ้งเตือน (Information Banner) ของแต่ละหน้า

ไฟล์นี้ให้ **ผู้ดูแลระบบเป็นคนเขียน** แล้วส่งกลับมา · ผู้พัฒนาจะนำข้อความไปใส่ใน
`src/constants/ui.ts` ให้ตรงกับที่เขียนไว้ตรงนี้ทุกตัวอักษร

> **สถานะ: ผู้พัฒนาร่างมาให้แล้วทุกหน้า (26 ส.ค. 2569)** — ข้อความในกล่องด้านล่างเป็น
> **ร่าง ไม่ใช่ของที่ใช้จริง** ยังไม่มีอะไรถูกนำขึ้นหน้าเว็บจนกว่าคุณจะตรวจและสั่ง
>
> แก้ทับได้เลย · ลบทิ้งถ้าไม่ต้องการ banner หน้านั้น · หน้าที่เขียนว่า *เสนอให้ไม่มี banner*
> คือหน้าที่ผู้พัฒนาเห็นว่าไม่มีอะไรต้องเตือนเพิ่ม พร้อมเหตุผลกำกับ ถ้าไม่เห็นด้วยเขียนทับได้

## Banner คืออะไร และไปโผล่ตรงไหน

กล่องข้อความพื้นสีอ่อนที่มีไอคอนอยู่ชิดซ้าย วางอยู่ **ใต้คำอธิบายหน้า เหนือช่องค้นหา/ตัวกรอง**
— ผู้ใช้อ่านก่อนลงมือกรอกเงื่อนไข ไม่ใช่หลังจากกรอกเสร็จแล้ว

```
┌─────────────────────────────────────────────┐
│  ชื่อหน้า                                    │
│  คำอธิบายหน้า                                │
├─────────────────────────────────────────────┤
│  ⓘ  ← ข้อความที่คุณเขียนในไฟล์นี้ไปอยู่ตรงนี้   │
├─────────────────────────────────────────────┤
│  [ ช่องค้นหา · ตัวกรอง ]                     │
├─────────────────────────────────────────────┤
│  ผลลัพธ์ · ตาราง · รายการ                     │
└─────────────────────────────────────────────┘
```

หน้าที่ไม่มีช่องค้นหา (เช่น หน้าภาพรวม · ค่าตั้งทั่วไป) ตำแหน่งเหมือนกัน คือใต้คำอธิบายหน้า
เหนือเนื้อหาส่วนแรก

## กติกาการเขียน

| ข้อ | เหตุผล |
|---|---|
| **1–2 บรรทัด (ไม่เกิน ~120 ตัวอักษร)** | ยาวกว่านี้ผู้ใช้จะข้ามไม่อ่าน แล้ว banner จะไร้ค่าทุกหน้า |
| **บอกสิ่งที่ผู้ใช้ต้องรู้ก่อนลงมือ** ไม่ใช่บรรยายว่าหน้านี้คืออะไร | คำอธิบายหน้าอยู่ใต้ชื่อหน้าอยู่แล้ว เขียนซ้ำคือเสียที่เปล่า |
| **เขียนสิ่งที่ระบบทำจริง** ไม่ใช่สิ่งที่อยากให้เป็น | ผู้ใช้จะเชื่อ banner แล้วทำตาม ถ้าไม่ตรงจะเสียความเชื่อถือทั้งระบบ |
| **เว้นว่าง = ไม่ต้องมี banner** | หน้าที่ไม่มีอะไรต้องเตือนจริง ๆ ปล่อยว่างดีกว่าใส่ข้อความกำกวม |
| **ห้ามใส่ชื่อคน เบอร์โทร หรือข้อมูลที่เปลี่ยนบ่อย** | ข้อความอยู่ในโค้ด แก้ทีต้องขึ้นระบบใหม่ |

ตัวอย่างที่ **ดี** — บอกสิ่งที่มีผลต่อการตัดสินใจ
> เรียงตามความเร่งด่วนก่อน แล้วจึงตามลำดับเวลาที่ส่งเข้ามา — ใครส่งก่อนได้เลขก่อน

ตัวอย่างที่ **ไม่ดี** — บรรยายสิ่งที่เห็นอยู่แล้ว
> หน้านี้แสดงรายการหนังสือที่รอออกเลข

# หน้าที่ไม่ได้อยู่ในเมนู (เข้าจากปุ่มหรือลิงก์)

หน้าเหล่านี้เป็นฟอร์มหรือหน้ารายละเอียด **ไม่มีคู่ "ตัวกรอง → ผลลัพธ์"** ให้วาง banner
ถ้าต้องการข้อความ จะไปอยู่ใต้ชื่อหน้า เหนือฟอร์ม · เขียนเฉพาะหน้าที่ต้องการจริง

## สร้างหนังสือ
- **ที่อยู่:** `/documents/new` (ปุ่ม "สร้างหนังสือ" จากร่างของฉัน)

```
เอกสารชั้นความลับต้องระบุผู้รับเป็นรายบุคคล เวียนถึงทั้งหน่วยงานไม่ได้
```

## ลงทะเบียนหนังสือรับ
- **ที่อยู่:** `/registry/incoming/new` (ปุ่มจากหน้าทะเบียนรับ)

```
กดบันทึกแล้วระบบออกเลขรับทันที — ตรวจวันที่รับและเลขที่หนังสือของผู้ส่งให้ถูกก่อน
```

## รายละเอียดเอกสาร
- **ที่อยู่:** `/documents/[id]` (คลิกจากตารางใดก็ได้)

```
(เสนอให้ไม่มี banner — หน้านี้บอกสถานะ ผู้รับ และสิ่งที่ทำต่อได้ผ่านแผงของตัวเองอยู่แล้ว)
```

## แก้ไขเอกสาร
- **ที่อยู่:** `/documents/[id]/edit` (ปุ่มแก้ไขในหน้ารายละเอียด)

```
(เสนอให้ไม่มี banner — ฉบับที่แก้ไม่ได้จะขึ้นแถบเตือนพร้อมเหตุผลอยู่แล้วเมื่อเปิดหน้า)
```

# เมื่อเขียนเสร็จ

ส่งไฟล์นี้กลับมา ผู้พัฒนาจะ

1. นำข้อความไปใส่ `src/constants/ui.ts` — ข้อความทั้งหมดอยู่รวมกันที่เดียว ไม่กระจายในหน้าเว็บ
2. วาง banner ตามตำแหน่งที่ระบุไว้ในแต่ละหัวข้อ
3. หน้าที่เว้นว่างไว้จะไม่มี banner (ไม่ใส่กล่องเปล่า)

**แก้ทีหลังได้เสมอ** — ส่งไฟล์นี้กลับมาใหม่พร้อมข้อความที่แก้แล้ว บอกว่าแก้หน้าไหนบ้างก็พอ
