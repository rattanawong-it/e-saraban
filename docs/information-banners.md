# ข้อความแจ้งเตือน (Information Banner) ของแต่ละหน้า

ไฟล์นี้ให้ **ผู้ดูแลระบบเป็นคนเขียน** แล้วส่งกลับมา · ผู้พัฒนาจะนำข้อความไปใส่ใน
`src/constants/ui.ts` ให้ตรงกับที่เขียนไว้ตรงนี้ทุกตัวอักษร

## Banner คืออะไร และไปโผล่ตรงไหน

กล่องข้อความพื้นสีอ่อนที่มีไอคอนอยู่ชิดซ้าย วางอยู่ **ใต้ส่วนค้นหา/ตัวกรอง เหนือผลลัพธ์**
ของแต่ละหน้า

```
┌─────────────────────────────────────────────┐
│  ชื่อหน้า                                    │
├─────────────────────────────────────────────┤
│  [ ช่องค้นหา · ตัวกรอง ]                     │
├─────────────────────────────────────────────┤
│  ⓘ  ← ข้อความที่คุณเขียนในไฟล์นี้ไปอยู่ตรงนี้   │
├─────────────────────────────────────────────┤
│  ผลลัพธ์ · ตาราง · รายการ                     │
└─────────────────────────────────────────────┘
```

หน้าที่ไม่มีช่องค้นหา (เช่น หน้าภาพรวม · ค่าตั้งทั่วไป) banner จะอยู่ **ใต้ชื่อหน้า เหนือเนื้อหา**

## กติกาการเขียน

| ข้อ | เหตุผล |
|---|---|
| **1–2 บรรทัด (ไม่เกิน ~120 ตัวอักษร)** | ยาวกว่านี้ผู้ใช้จะข้ามไม่อ่าน แล้ว banner จะไร้ค่าทุกหน้า |
| **บอกสิ่งที่ผู้ใช้ต้องรู้ก่อนลงมือ** ไม่ใช่บรรยายว่าหน้านี้คืออะไร | คำอธิบายหน้าอยู่ใต้ชื่อหน้าอยู่แล้ว เขียนซ้ำคือเสียที่เปล่า |
| **เขียนสิ่งที่ระบบทำจริง** ไม่ใช่สิ่งที่อยากให้เป็น | ผู้ใช้จะเชื่อ banner แล้วทำตาม ถ้าไม่ตรงจะเสียความเชื่อถือทั้งระบบ |
| **เว้นว่าง = ไม่ต้องมี banner** | หน้าที่ไม่มีอะไรต้องเตือนจริง ๆ ปล่อยว่างดีกว่าใส่ข้อความกำกวม |
| **ห้ามใส่ชื่อคน เบอร์โทร หรือข้อมูลที่เปลี่ยนบ่อย** | ข้อความอยู่ในโค้ด แก้ทีต้องขึ้นระบบใหม่ |

ตัวอย่างที่ **ดี** — บอกสิ่งที่มีผลต่อการตัดสินใจ
> เรียงตามความเร่งด่วนก่อน แล้วจึงตามลำดับเวลาที่ส่งเข้ามา — ใครส่งก่อนได้เลขก่อน

ตัวอย่างที่ **ไม่ดี** — บรรยายสิ่งที่เห็นอยู่แล้ว
> หน้านี้แสดงรายการหนังสือที่รอออกเลข

# เมื่อเขียนเสร็จ

ส่งไฟล์นี้กลับมา ผู้พัฒนาจะ

1. นำข้อความไปใส่ `src/constants/ui.ts` — ข้อความทั้งหมดอยู่รวมกันที่เดียว ไม่กระจายในหน้าเว็บ
2. วาง banner ตามตำแหน่งที่ระบุไว้ในแต่ละหัวข้อ
3. หน้าที่เว้นว่างไว้จะไม่มี banner (ไม่ใส่กล่องเปล่า)

**แก้ทีหลังได้เสมอ** — ส่งไฟล์นี้กลับมาใหม่พร้อมข้อความที่แก้แล้ว บอกว่าแก้หน้าไหนบ้างก็พอ
